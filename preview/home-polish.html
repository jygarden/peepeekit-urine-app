① 4 카드 아이콘 → 모두 블루 SVG 통일 (운동 아이콘 톤 기준)
· 내 몸의 신호 → 체크마크 + 알림 뱃지 (SVG)
· 나의 영양 → 클립보드 + 체크리스트 (SVG)
· 오늘의 운세 → 별 아이콘 (SVG)
· 오늘 운동 → 바벨 (SVG, 기존 유지)
→ 파스텔 믹스 제거, 브랜드 톤 통일, 성숙한 느낌

② 휑함 해결 · 오늘의 요약 카드 추가
· 왼쪽: 섭취 달성률 링 (60%)
· 중앙: kcal · 식사 상황 요약
· 우측: ⭐ 메뉴 버튼 (자주 먹는 메뉴로 통합)
· 하단: 단백질/탄수/지방/나트륨 미니 뱃지
→ "오늘 뭐 얼마나 먹었나" 한눈에

③ "자주 먹는 메뉴" 노랑 바 제거
→ 요약 카드 안 "⭐ 메뉴" 버튼으로 통합. 노랑 돌출 요소 사라짐.

④ 메이트 최근 활동 미리보기 추가
· 메이트 2-3명 최근 식단/운동 간단히
· "모두 보기" → 메이트 탭으로
→ SNS 느낌, 다시 돌아오고 싶게

⑤ 스토어 배너 압축 — 작게 줄여서 하단 자리만 차지

이대로 OK면 index.html 반영 · SVG 아이콘 삽입. 아니면 수정 포인트 말해줘.
