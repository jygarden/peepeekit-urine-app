🤝 메이트 운동 루틴 공유 (추가)

작동 방식
· 내 운동 루틴 저장 (예: "월요일 가슴 루틴 — 벤치 4세트 / 덤벨 플라이 3세트 / 딥스 3세트")
· 메이트에게 공유 → 메이트가 그대로 가져다 쓰기
· 템플릿 리스트에서 "{이름}의 가슴 루틴" 선택하면 세트까지 자동 입력

왜 좋음
· PT가 회원에게 "이번주 루틴" 전달 (B2B 핵심)
· 친구끼리 "오늘 같이 가슴 하자" 공유
· 좋은 루틴은 메이트 네트워크 내에서 전파 → 자연스런 리텐션

UI
· 운동 모달 상단에 "루틴 불러오기 ↓" 버튼
· 운동 모달 하단에 "이 루틴 저장 💾" 버튼
· 메이트 피드 "💪 운동 탭"에서 "이 루틴 가져오기 📥" 버튼

📋 작업 범위 요약

Phase G2 · 운동 전면 개편
① 운동 DB 상수 (EXERCISE_DB) — 120+ 종, 부위별 분류, 유산소 플래그
② 운동 모달 3단계 UI (부위 → 운동 다중선택 → 세트 입력)
③ 유산소 전용 입력 (거리·시간 · 자동 페이스/칼로리 계산)
④ 가이드라인 (목표별 유산소 추천)
⑤ 루틴 저장·불러오기 (localStorage + 서버 선택적)

Phase I-2 · 메이트 소셜 (별도 작업)
① 좋아요 (mate_likes 테이블)
② 댓글 (mate_comments 테이블)
③ 챌린지 (mate_challenges)
④ 통합 피드 (전체 메이트 식단·운동 타임라인)
⑤ 운동 루틴 공유 (workout_routines 테이블)

우선순위 추천
1. Phase G2 운동 전면 개편 (지금 바로 · 3시간 작업)
2. 메이트 운동 피드 (이미 구조 있음 · 1시간 작업)
3. 좋아요 · 댓글 (2시간 작업)
4. 루틴 공유 (2시간 작업)
5. 챌린지 · 통합 피드 (1일 작업)
