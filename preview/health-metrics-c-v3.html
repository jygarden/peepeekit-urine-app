🧪 소변검사 카드 설계
접힌 상태 (기본):
· 10개 중 정상/주의/위험 개수 (예: "8 정상 · 2 주의")
· 도넛 차트 (초록/노랑/빨강 비율)
· 주의 항목 이름 명시 (단백뇨, 우로빌리노겐 등)
· 10개 미니 바 (한 줄로 전체 상태 한눈에)
· "10개 항목 전체 보기" 버튼

펼친 상태: 10개 항목 각각 수치 + 정상/주의 태그 + 재검사 버튼

💡 소변검사 추천 연계 (연결고리)
· 단백뇨 + → 저염, 신장 보호 식단
· 포도당 + → 저당, 당뇨 주의 식단
· 케톤 + → 탄수화물 보충
· 잠혈 + → 철분 보충, 요로 보호
· 우로빌리노겐 ↑ → 간 보호 식단 (알코올 금지)
