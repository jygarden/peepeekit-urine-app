② Apple Health / 삼성헬스 연동 (갤럭시워치, 블루투스 혈압계) 		새로 구현
· 모달 1개
· API 확장

② 10개 항목 각각 선택 (음성 / +1 / +2 / +3) 		① 이미 구현 ✅

💡 가장 간단한 접근: 각 메트릭 카드에 "+ 입력" 버튼 → 모달로 숫자 입력 (3초). 혈당·혈압은 손가락 터치 몇 번이면 끝.
스마트워치/CGM 연동은 Phase 2 (앱 출시 후 상위 기능).
🎨 색상 톤 비교
· A안 (소프트 블루) — 안전, 현재 톤과 가장 가까움, 음식명은 밝은 블루 밑줄로 강조
· B안 (화이트 반전) — 가장 밝고 깔끔, 톤 다운 · 초보자 친근
· C안 (다크 + 민트) — 프리미엄 느낌 · 피트니스 브랜드스러움 · B2B 프로페셔널

바뀐 거:
❌ "내 주변" 버튼 제거 (2 버튼으로: 다른 추천 / 자세히)
❌ 노란 형광펜 하이라이트 제거
✅ 음식명은 밑줄 or 다른 색상으로 더 부드럽게 강조
