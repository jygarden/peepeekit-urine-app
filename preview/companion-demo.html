① 홈 추천 카드 (작은 안내자 · 68×68)

오늘 저녁,
월남쌈 어때?
단백질 풍부해서 든든할 거야 💪

② 분석 중 화면 (큰 버전 · 200×200)

한 끼를 살펴보고 있어요
작은 물결이 부드럽게 돌아요.

③ 상태 전환 테스트 (실제엔 숨길 UI)

적용 지점 (실제 앱 연동)
· 홈 추천 카드 오른쪽 작은 안내자 → 추천 로딩 중 thinking → 추천 도착 시 result
· 식사 분석 로딩 화면 큰 버전 → 분석 중 thinking → 결과 받으면 result → 기록 저장 시 saved
· 실패 시 result 쓰지 않기 — 에러나 미달 결과엔 그냥 idle 유지 (성공 표정으로 거짓 긍정 X)
· 부정적 결과에도 평가 표정 X — 나트륨 과다여도 캐릭터 표정은 중립 (사실 전달은 텍스트 몫)

사용 코드
const c = HealthCompanion.mount('#homeCompanion', {size: 68});
c.setState('thinking'); // 추천 로딩
c.setState('result'); // 추천 도착 (2.6초 후 idle 자동)
c.setState('saved'); // 기록 저장 (2초 후 idle 자동)
c.destroy(); // 제거
